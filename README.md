# فونك | PhoneK — دليل التشغيل والإطلاق

هذا المشروع كود Flutter منظم واحترافي (بدون أخطاء برمجية) يطبّق التصميم والشاشات
الأساسية لتطبيق PhoneK بناءً على قراراتك. **يعمل فوراً بعد ربطه بمشروع Flutter**
ببيانات تجريبية محلية (Mock Data) — أي أنك تقدر تشغّله وتتصفحه اليوم بدون Firebase.

لكن بعض الميزات (تسجيل دخول Google الحقيقي، حفظ الإعلانات الفعلي، الشات الفوري بين
جهازين، الإشعارات) تحتاج **حساب Firebase خاص بك** لأنها تتطلب مفاتيح API لا يقدر
أي طرف ثالث توليدها نيابة عنك.

---

## ✅ ما هو مكتمل وشغّال الآن (بدون أي إعداد إضافي)

- الهوية البصرية: مظهر داكن (أسود/ذهبي)، دعم كامل للعربية واتجاه RTL
- الشاشة الرئيسية: بحث، فلاتر (مدينة/ماركة/سعر)، ترتيب، سحب للتحديث، حالة "لا نتائج"
- شبكة عرض الهواتف: شارات (مميز / تم البيع / به عيوب)، خصم بالسعر القديم مشطوب
- صفحة تفاصيل الهاتف: جدول مواصفات كامل، فلترة صحة البطارية للآيفون فقط، ملاحظات
  الأعطال بالأحمر، الملحقات، هواتف مشابهة، تنبيه أمان اللقاء
- أزرار التواصل: اتصال مباشر + واتساب بنص جاهز + محادثة داخلية + تقديم عرض سعر
- شاشة إضافة إعلان: كل الحقول (الحالة، الملحقات، الضمان، السعر/التفاوض/اتصل للسعر،
  التحقق من الحد الأدنى للسعر، حفظ كمسودة)
- المفضلة: مع ميزة السحب للحذف (Swipe to delete)
- الشات: فقاعات رسائل، علامات القراءة، إرسال موقع، مؤشر "متصل الآن"
- صفحة الحساب: تسجيل خروج، حذف حساب (بتأكيد)، لوحة تحكم أدمن بإحصائيات أساسية

## ⏳ ما يحتاج ربطك بـ Firebase لتفعيله فعلياً

كل نقطة أدناه موجودة في الواجهة والكود لكنها تعمل حالياً بـ "بيانات وهمية محلية"
(محدد بتعليق `// TODO` في مكانه بالكود بالضبط):

| الميزة | أين في الكود |
|---|---|
| تسجيل دخول Google حقيقي | `lib/screens/login_screen.dart` |
| حفظ الإعلانات الجديدة فعلياً في قاعدة بيانات | `lib/screens/add_phone_screen.dart` |
| رفع الصور الحقيقية (كاميرا/معرض) | `lib/screens/add_phone_screen.dart` |
| الشات الفوري بين جهازين حقيقيين | `lib/screens/chat_screen.dart` |
| الإشعارات (Push Notifications) | يحتاج `firebase_messaging` |
| لوحة تحكم الأدمن ببيانات حقيقية | `lib/screens/admin_dashboard_screen.dart` |

## 🚀 خطوات التشغيل الأولى (على جهازك)

### 1. تثبيت الأدوات (مرة واحدة فقط)
- ثبّت **Flutter SDK**: https://docs.flutter.dev/get-started/install
- ثبّت **Android Studio** (لإدارة أجهزة أندرويد الوهمية ولتوقيع الـ APK)
- تأكد أن كل شيء سليم بتشغيل: `flutter doctor` (لازم يكون كل شيء بعلامة ✔)

### 2. توليد مجلدات android/ios (خطوة ضرورية ولا يمكن تخطّيها)
هذا المشروع يحتوي فقط على مجلد `lib/` وملف `pubspec.yaml` — وهذا **مقصود ومهم**:
مجلدات `android/` و`ios/` يجب أن تُولَّد تلقائياً من إصدار Flutter المثبت فعلياً على
جهازك (وليس مكتوبة يدوياً)، لأن كتابتها يدوياً بدون مطابقة دقيقة لإصدار Gradle/Kotlin/
Flutter لديك هي **السبب الأكثر شيوعاً لأخطاء البناء** في أي مشروع Flutter جاهز يُنسخ
من مكان آخر.

نفّذ داخل مجلد المشروع:

```bash
cd phonek_app
flutter create . --org com.phonek --project-name phonek_app
```

هذا الأمر **لن يمسح أياً من ملفاتك** الموجودة في `lib/` أو `pubspec.yaml`؛ فقط يضيف
مجلدات `android/` و`ios/` سليمة ومطابقة لجهازك.

### 3. تثبيت الحزم
```bash
flutter pub get
```

### 4. التشغيل التجريبي (بالبيانات الوهمية، بدون Firebase)
وصّل هاتف أندرويد بكيبل USB (مع تفعيل "خيارات المطورين" و"تصحيح USB")، أو شغّل
محاكي من Android Studio، ثم:
```bash
flutter run
```
التطبيق هيشتغل ويقدر تتصفحه بالكامل بالبيانات التجريبية الثلاثة الموجودة.

## 🔥 ربط Firebase (لتفعيل تسجيل الدخول، الشات الحقيقي، حفظ الإعلانات)

1. افتح https://console.firebase.google.com وأنشئ مشروع جديد (مجاني - خطة Spark تكفي للبداية)
2. من داخل المشروع، أضف تطبيق Android باسم الحزمة نفسه اللي استخدمته في الخطوة 2
   (`com.phonek.phonek_app`)، وحمّل ملف `google-services.json` وضعه في `android/app/`
3. فعّل من لوحة Firebase: **Authentication** (فعّل Google Sign-In) و **Firestore
   Database** و **Storage** و **Cloud Messaging**
4. ثبّت أداة FlutterFire ثم اربط المشروع تلقائياً:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
   هذا الأمر يولّد لك ملف `lib/firebase_options.dart` تلقائياً ومربوط بحسابك.
5. في `pubspec.yaml` أزل علامة `#` عن الحزم المذكورة تحت "عند ربط Firebase"
6. في `lib/main.dart` أضف قبل `runApp`:
   ```dart
   WidgetsFlutterBinding.ensureInitialized();
   await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);
   ```
7. استبدل تدريجياً كل تعليق `// TODO` المذكور في الجدول أعلاه بكود قراءة/كتابة حقيقي
   من Firestore بدل البيانات الوهمية في `lib/data/mock_data.dart`

## 📦 بناء ملف APK للنشر والتوزيع

بعد التأكد أن التطبيق يعمل بدون أخطاء بـ `flutter run`:

```bash
flutter build apk --release --obfuscate --split-debug-info=build/debug-info
```

الملف الناتج تجده في:
```
build/app/outputs/flutter-apk/app-release.apk
```

⚠️ **قبل التوزيع الفعلي للناس** تأكد من:
- توليد مفتاح توقيع خاص بك (Signing Key) بدل التوقيع التجريبي الافتراضي — راجع:
  https://docs.flutter.dev/deployment/android#signing-the-app
- إضافة أيقونة حقيقية للتطبيق بدل الافتراضية (استخدم حزمة `flutter_launcher_icons`)
- اختبار التطبيق فعلياً على جهاز أو جهازين أندرويد حقيقيين قبل التوزيع الواسع

## أسئلة متوقعة

**"ليش ما جهزت لي APK جاهز مباشرة؟"**
لأن أي APK حقيقي وموقّع يحتاج توليده من جهازك بعد `flutterfire configure` بمفاتيحك
الخاصة — أي APK أعطيك إياه بدون هذه الخطوة إما لن يعمل فيه تسجيل الدخول/الشات، أو
سيحتوي مفاتيح تجريبية غير آمنة للنشر العام.

**"هل أقدر أنشر بدون Firebase؟"**
نعم تماماً — التطبيق يعمل ويُعرض بشكل كامل بالبيانات التجريبية. فقط أزرار تسجيل
الدخول/نشر إعلان جديد/الشات الحقيقي هتبقى "تجريبية" (تعرض رسالة تنبيه بدل التنفيذ
الفعلي) لحد ما تربط Firebase.
