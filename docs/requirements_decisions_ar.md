# قرارات PhoneK المستخرجة من إجابات الاستبيان

هذا الملف يلخص القرارات الصريحة القابلة للتنفيذ من ملف الإجابات المرفق. القرارات الغامضة أو التي لا يظهر لها اختيار نهائي لا تُنفذ بالتخمين.

| المجال | القرار المعتمد | أثر التنفيذ |
|---|---|---|
| المنصة | هواتف فقط عند البداية، مع دعم Android من 6.0 | عدم توسيع الفئات قبل تثبيت سوق الهواتف |
| التواصل | اتصال + WhatsApp + محادثة داخلية | إبقاء قنوات التواصل الثلاث مع حماية الرقم |
| الحسابات | التصفح كزائر، والتسجيل عند الإضافة أو التواصل؛ Google بدون كلمة مرور | الحفاظ على Supabase Auth وGoogle OAuth |
| البائعون | تمييز المحلات، مع توثيق خاص للمحلات | إضافة صلاحيات وبيانات توثيق للمحل فقط |
| الإعلانات | مراجعة الأدمن قبل النشر، ومهلة الإعلان 30 يومًا، مع إدارة إعلاناتي | حالات pending/active/expired/sold وإجراءات المالك |
| الصور | حتى 5 صور، ضغط قبل الرفع، مع ترتيب الصور والعلامة المائية | تحسين مسار رفع الصور وإضافة image ordering |
| المواصفات | حالة محددة، ملحقات كخيارات، وصحة البطارية للـ iPhone فقط | عدم إظهار فلتر البطارية لغير iPhone |
| البحث | فلترة السعر، الماركة، المدينة، RAM/Storage، وتحديث النتائج مباشرة | تطوير HomeScreen والفلاتر مع حفظ بحث أخير محليًا |
| المفضلة | حفظها في حساب المستخدم | جدول favorites وسياسات RLS |
| الطلبات | طلبات الشراء مخصصة للمحلات والرد عليها | عدم فتح المسار لكل الزوار قبل ربطه بالصلاحيات |
| الخصوصية | رقم البائع للمستخدم المسجل فقط، والموقع النصي في MVP | حماية أرقام الاتصال وعدم إضافة GPS الآن |
| الثقة | علامة ضرر وصورة مكبرة للكسور، تقييمات للمحلات المعتمدة فقط | إضافة حقول ومراجعة قبل التقييم |
| الشات | نصي مع Realtime عند الحاجة، وموقع اللقاء مستقبلاً، بلا صوت في MVP | عدم إدخال الصوت قبل البنية التخزينية والإشعارات |
| الإشعارات | صندوق إشعارات داخل التطبيق مع إمكانية كتم الترويج | تأجيل Push الجماعي إلى دفعة مستقلة |
| الإدارة | لوحة داخل التطبيق للأدمن، مراجعة بموافقة/رفض، وسجل نشاط | إضافة صلاحيات إدارية حقيقية وaudit log |
| الأداء | Cache للمفضلة والإعلانات الشخصية، ضغط الحزم، وواجهات بسيطة | الحفاظ على الأداء وعدم إضافة أنيميشن ثقيل |
| القانون | صفحة شروط وخصوصية وFAQ | إضافة صفحات محتوى ثابتة داخل التطبيق |
| الإطلاق | بدء التنفيذ فورًا، مع APK قابل للتنزيل ونسخة Web | CI يبني Debug حاليًا، وRelease signing لاحقًا |

## قرارات تحتاج تثبيتًا إضافيًا

توجد في النص إجابات متداخلة أو غير مرقمة بوضوح لبعض الأسئلة، خصوصًا المجموعات التي كُتبت بصيغة حروف متتابعة. لذلك لا أستنتج منها قرارات إضافية حول الدفع، الشحن، GPS، التسعير، أو مدة الإعلان إلا عند وجود ملخص صريح. كما أن ملف الإجابات لا يثبت تطبيق migration في Supabase أو وجود بيانات إنتاجية.
